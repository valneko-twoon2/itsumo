# 新規プロジェクトのセットアップ

ソースコードがまだ無いので、**調べて決まりを作ることはできない**。推測で規則やスキルを作らない。代わりに、質問から最小の AGENTS.md を作り、コードができてから育てる。

## 手順

1. 質問する（`/itsumo:clarifying-requests` の聞き方で、選択肢と推奨を添える）。次の点のうち、まだ決まっていないものだけ聞く。
   - 何を作るか（1〜2 文）。
   - 言語とフレームワーク、パッケージマネージャ。
   - テストの道具と、書く流儀（テストを先に書くか）。
   - リントと整形の道具。
   - 守ってほしい決まり（コミットの流儀、ブランチ運用、使ってはいけない依存）。
   - 使う環境（OS、Node.js や Python のバージョン）。
2. 答えから、最小の AGENTS.md を作る（概要、決まったコマンド、決まり）。コマンドは**まだ存在しない**ので、「予定」と分かるように書くか、コマンドが決まるまで省く。
3. 必要なら次も提案する（ユーザーの了承を得て作る）。
   - `.gitignore`（言語に合うもの）。
   - `.gitattributes`（改行の方針。例: `* text=auto eol=lf`）。
   - `.editorconfig`。
4. 規則（rules）とスキル（skills）は**作らない**。

## 最後に

AGENTS.md の末尾に、次の 1 行を入れる。

```
コードが育ったら `/itsumo:setting-up-project` を再実行して、この決まりを見直す。
```

2 回目の実行では、コードを調べて、決まりや規則・スキルの提案ができる。
